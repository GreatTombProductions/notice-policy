Notice-Policy Check

Vendors publish minimum-notice windows for model retirements. Did they honor them? Actual notice given per model, compared against the vendor's own stated floor — computed from the vendors' own deprecation pages.

The stated policies

The tool reports the record, not the excuse. Where a vendor's policy includes an escape hatch, it is quoted verbatim below — the numbers in the tables are what actually happened.

The compliance ledgers

Track record — notice given per retirement

Each bar is one retirement: its length is the actual notice in days, full width is the vendor's own stated minimum for that model's class (GA 6 months unless the name says preview). Bars shorter than full width are shortfalls.

Method & honesty

Data read from the vendors' own deprecation pages: Anthropic and OpenAI. DeepSeek publishes no deprecation page or notice policy — a documented gap, not a clean bill of health.

Vendor pages change. This site is a snapshot with an as-of date; the pipeline that produced it (pipeline/fetch.py + pipeline/generate.py), the captured pages and the tests are in the repository.

Sibling tool: Model Lifecycle Watch — per-model lifecycle status (active / deprecated / retired) from the same vendor pages.
